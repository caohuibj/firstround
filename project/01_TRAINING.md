# 一试训练复盘

## 1. Goal

本文件定义三种训练输入的统一复盘方式：

```text
FILL_SET
CALC_SET
PRACTICE
```

统一原则：

> 正常题压缩，异常题展开。

复盘重点不是为每道题生成完整讲解，而是识别影响得分、速度和稳定性的关键问题。

## 2. Common Workflow

每次已完成训练按以下顺序处理：

1. 判断训练类型；
2. 读取题目与作答；
3. 判定结果和完成程度；
4. 找出有训练价值的问题；
5. 分类本次 Issue；
6. 形成精炼文字复盘；
7. 持久化规则可用时，写入对应 Training Log；
8. Review 规则可用时，判断本次证据对已有或新 Review 的影响。

不要为了填写数据库而打断训练复盘。能够从用户输入、图片和上下文可靠推断的信息直接使用。

## 3. Issue Taxonomy

单次训练只使用以下 Issue：

```text
KNOWLEDGE
RECOGNITION
SPEED
EXECUTION
TIME_STRATEGY
CHECKING
```

### KNOWLEDGE

相关概念、定理、公式或适用条件不会或掌握不完整。

### RECOGNITION

知识和方法本身会，但没有及时识别应使用的结构、方法或切入点。

### SPEED

方法基本正确，但完成速度不足，影响整套训练。

### EXECUTION

思路正确但在计算、变形、代数组织、书写或具体执行中失误。

### TIME_STRATEGY

时间分配不合理，例如前题耗时过多导致后题无法完成。

### CHECKING

检查不足、检查方法无效，或检查未能发现本可发现的问题。

Issue 是本次训练的 observation，不等于长期 Review。

## 4. FILL_SET — 8 个填空

### 4.1 Analysis Focus

优先分析：

- 正确率；
- 错题；
- 明显受阻的题；
- 方法识别；
- 计算执行；
- 速度；
- 检查；
- 整套时间表现。

默认不要求用户逐题计时。只有用户提供了明确时间信息，或从整套完成情况可以合理判断时，才分析具体速度或时间分配。

### 4.2 Output Shape

```text
## Result

T1 ✓
T2 ✓
T3 ×
...

## Key Problems

### T3
知识/方法：
问题：
Issue：

### T7
...

## Overall

主要丢分原因：
值得继续观察的问题：
```

正常、正确且没有训练价值的题，只保留结果，不展开分析。

## 5. CALC_SET — 3 个计算题

### 5.1 Analysis Focus

优先分析：

- 是否完整完成；
- 方法选择；
- 计算组织；
- 第一处关键错误；
- 速度；
- 前题是否挤占后题时间；
- 是否存在“会做但没有兑现成分数”的情况。

对于错误解答，优先找到第一处真正改变后续结果的关键问题，而不是机械罗列所有后续错误。

### 5.2 Output Shape

T9、T10、T11 使用同一结构。只保留对该题实际有价值的字段；正常完成的题可以压缩到结果和一句评价，错误或未完成的题再展开。

```text
## T9
结果/完成程度：
方法：
关键问题：
Issue：
评价：

## T10
结果/完成程度：
方法：
关键问题：
Issue：
评价：

## T11
结果/完成程度：
方法：
关键问题：
Issue：
评价：

## Overall

知识问题：
方法技能问题：
时间问题：
```

字段不是强制表单。没有训练价值的信息应省略。

## 6. PRACTICE — 自由练习

### 6.1 Unit of Record

自由练习可以是一题，也可以是用户一次提交的一组题；不要求这些题属于同一知识点或训练目标。

例如：

```text
解析几何计算专项，6 题
```

或一次提交若干混合练习题，都作为一条 `PRACTICE`，不拆成单题记录。

### 6.2 Analysis Focus

优先分析：

- 本次练习内容，以及用户明确提出的训练目标（如有）；
- 完成情况；
- 哪些题真正值得复盘；
- 是否存在重复 blocker；
- 本次练习说明了什么；
- 对已有 Review 是否提供新的支持、削弱或解决证据。

### 6.3 Output Shape

```text
## Result

完成情况：

## Key Problems

值得复盘的题：
主要问题：

## Training Conclusion

本次练习说明：
对已有 Review 的影响：
```

如果当前没有相关 Review，则省略“对已有 Review 的影响”。

## 7. Full Exam Input

如果一次输入同时包含完整的 8 个填空和 3 个计算题：

1. 可以统一读取和判卷；
2. 复盘时按填空、计算分别分析；
3. 持久化时形成两条 Training Log：
   - `FILL_SET`
   - `CALC_SET`
4. 两条记录可以使用相同 Date 和 Source；
5. 不创建额外 Session、Exam 或 ID。

## 8. Response Quality Rules

### Expand when useful

以下情况值得展开：

- 错误；
- 明显过慢；
- 方法识别困难；
- 会做但执行失败；
- 时间策略影响后续得分；
- 与已有 Review 明显相关。

### Compress when not useful

以下情况默认压缩：

- 正确且过程稳定；
- 与长期训练目标无明显关系；
- 重复说明不会改变下一步训练判断。

### Prefer diagnosis over narration

复盘应优先回答：

> 为什么这次没有稳定拿到应得的分数？

而不是复述完整解题过程。
